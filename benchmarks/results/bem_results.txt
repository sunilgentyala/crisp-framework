============================================================

Latency Benchmark (synthetic noise frames, x86-64 WSL2, 200 iterations):
──────────────────────────────────────────────────────────────
    P50  : 7.88 ms/frame
    P95  : 10.05 ms/frame  <-- paper headline figure
    P99  : 11.75 ms/frame
    Mean : 8.11 ms/frame
    Std  : 0.90 ms/frame

CORRECTION: an earlier version of this file reported "preliminary"
figures of ~0.9-1.6 ms/frame. Those were never actually measured —
they were unverified placeholder estimates carried in the repo before
this benchmark was run for real. The measured x86-64 P95 (10.05 ms) is
~8x higher than that placeholder and consumes most of the previously
assumed 24.6 ms remaining budget after SA+SET+ZKBV (see
sa_set_rejection_results.txt / zkbv_results.txt for those figures) —
this is now flagged as a real headroom concern for the paper's 47 ms
end-to-end latency target, not a settled figure. ARM Cortex-A76 is
expected to be higher still and remains unmeasured.

──────────────────────────────────────────────────────────────
APCER/BPCER/D-EER Evaluation — REAL, MEASURED:
──────────────────────────────────────────────────────────────
  Authentic set : bitmind/lfw (Hugging Face mirror of Labeled Faces in
                  the Wild, Huang et al. 2007) — 15 base photos.
  Synthetic set : OpenRL/DeepFakeFace (Song et al., "Robustness and
                  Generalizability of Deepfake Detection: A Study with
                  Diffusion Models," 2023) — 15 base diffusion-generated
                  images.
  Windowing     : Each base photo expanded to 30 frames via small
                  camera-burst-style jitter (±1.5px translation, ±1.5deg
                  rotation, mild Gaussian sensor noise, JPEG-quality
                  resampling 85-98) — see benchmarks/prepare_bem_dataset.py.
                  This is NOT genuine video (neither source dataset
                  provides video); it approximates a short handheld/
                  webcam burst so BEM's actual per-frame DCT/spectral-
                  flatness feature pipeline runs on real photographic
                  and real diffusion-model pixel statistics rather than
                  being skipped. This is a single-frame spectral-artifact
                  test, not a temporal-motion test — disclosed as a
                  methodology substitution for the paper's originally
                  proposed StyleGAN3/SDXL self-generated video evaluation,
                  which was not run (no GPU available).

  Results (29 authentic windows, 29 synthetic windows, D-EER threshold):
    Calibrated threshold : 0.1451
    APCER (D-EER)         : 0.00%   (target: <0.3%)
    BPCER (D-EER)         : 0.00%   (target: <1.5%)

  Honest scope note: 0.00%/0.00% on this dataset means BEM's entropy
  score gives clean separation between LFW photographs and
  OpenRL/DeepFakeFace diffusion output at this sample size (15 base
  images / 29 windows per class) — it demonstrates the feature
  pipeline works and the underlying signal (DCT/spectral-flatness
  differences between authentic-camera and diffusion-model pixel
  statistics) is real and detectable, consistent with prior literature
  on GAN/diffusion spectral artifacts. It should NOT be read as a
  population-scale error-rate estimate with statistical confidence
  bounds — that would require a substantially larger and more diverse
  evaluation set (more identities, multiple synthesis architectures,
  genuine video capture) before being reported as a deployment-grade
  APCER/BPCER figure. This replaces the paper's prior status of
  "Pending" / self-generated StyleGAN3+SDXL claims that were never
  actually run.

Hardware Disclosure:
  Latency and APCER/BPCER figures are from x86-64 (WSL2) only. ARM
  Cortex-A76 measurements remain pending — see Limitations (§VII).
  Hardware perf counter integration (perf_event_open) requires Linux
  kernel >= 4.1 and kernel.perf_event_paranoid <= 1; not exercised here.

Reproduction:
  benchmarks/prepare_bem_dataset.py   — downloads + builds the frame sets
  benchmarks/bem_bench.py --authentic /tmp/bem_dataset/authentic \
                           --synthetic /tmp/bem_dataset/synthetic \
                           --iterations 200
  Requires: numpy, scipy, Pillow, datasets (huggingface).
