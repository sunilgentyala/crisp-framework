Closing the chain-of-trust gap behind biometric injection attacks

CRISP (Cryptographic Root-of-trust Identity and Sensor Provenance) is a four-component framework that anchors biometric authentication to attested physical hardware. OS-level injection tools — v4l2loopback, OBS Virtual Camera, LD_PRELOAD hooks — insert synthetic deepfake video upstream of every liveness and presentation-attack check that exists today. CRISP verifies the sensor itself, not just the stream it produces.

View on GitHub Paper Status Benchmark Guide

The problem

Modern biometric authentication assumes sensor input can be trusted. It cannot.

  • Injection bypasses PAD by design. Virtual-camera drivers and userspace hooks insert synthetic video directly into the OS media pipeline, upstream of every presentation-attack-detection and liveness check — ISO/IEC 30107-3 compliance offers zero protection against this attack class.
  • The attack is surging. Injection attacks grew 9× year-over-year through 2024, as deepfake generation tools became commodity software.
  • Spoofing the camera, not the face. These attacks impersonate the sensor itself rather than presenting a fake face to a real camera, which is the one thing liveness detection was never designed to catch.

CRISP architecture

Four independent components sit between the physical sensor and the authentication decision. A stream is accepted only if all four pass.

Authentication Decision Module            ← ACCEPT only if all four pass
Blocks AC-2, AC-3

SA · Sensor Attestation

TPM 2.0-anchored attestation binds every frame to a hardware root of trust via an AIK-signed PCR quote, proving the data came from the physical sensor and not a driver-level or virtual-camera injection.

Blocks AC-4

SET · Secure Telemetry

An X25519MLKEM768 post-quantum hybrid handshake plus AES-256-GCM protects the sensor-to-verifier channel, closing off SDK hooking and LD_PRELOAD interception even against a future quantum adversary.

Template unlinkability

ZKBV · ZK Biometric Verify

A Groth16 zkSNARK over a BCH(2047,1723) fuzzy commitment proves a biometric match without ever transmitting the underlying template, eliminating replay and cross-database linkability.

Novel synthesis variants

BEM · Entropy Monitor

KL-divergence and spectral-flatness analysis over the live stream catch synthetic-generation artifacts that attestation and channel security alone can't — the last line of defense against novel deepfake variants.

Quick start

Reproduce the SA (TPM attestation) benchmark. See the Benchmark Guide for SET, ZKBV, and full prerequisites.

sudo apt install -y swtpm tpm2-tools python3-pip
pip install -r requirements.txt

mkdir -p /tmp/vtpm
swtpm socket --tpmstate dir=/tmp/vtpm --tpm2 \
  --server type=unixio,path=/tmp/vtpm/sock \
  --ctrl type=unixio,path=/tmp/vtpm/sock.ctrl \
  --flags not-need-init,startup-clear &

export TPM2TOOLS_TCTI="swtpm:path=/tmp/vtpm/sock"
tpm2_createprimary -C e -c /tmp/vtpm/primary.ctx
tpm2_evictcontrol -C o -c /tmp/vtpm/primary.ctx 0x81000001

python3 benchmarks/tpm_bench.py
